# SOLAFORM – Documentation

## Overview

This folder contains the main documentation required for the SOLAFORM Artificial Leaf project.

The documentation provides information about the project concept, costs, team, technical development, and overall system design.

## Required Documentation

### 1. Pitch Deck

The Pitch Deck is a presentation in PDF format with a maximum of **7 slides**.

It summarises the SOLAFORM project and includes:

* Introduction and problem statement
* Proposed solution
* Marketability and buildability
* Total cost of implementation
* Team members
* Team roles and responsibilities
* Pictures of the team members or individual team members

**File:** `Pitch_Deck.pdf`

### 2. Bill of Materials

The Bill of Materials (BOM) is a spreadsheet containing the components and costs required to build the SOLAFORM prototype.

For each component, the spreadsheet includes:

* Component name
* Quantity
* Cost per unit
* Supplier name
* Supplier stock code
* Direct URL/link to purchase the component
* Total cost

The final total cost of implementation is clearly highlighted in **red**.

**File:** `Bill_of_Materials.xlsx`

### 3. Holistic Build Document

The Holistic Build Document is a comprehensive document that brings together the different aspects of the SOLAFORM project.

It describes the project development, system design, technical implementation, testing, costs, buildability, marketability and other requirements relevant to the Technomania competition category.

The document connects the information presented in the project design, source code, testing and other project documentation.

**File:** `Holistic_Build_Document.pdf`

## Relationship to Other Folders

Folder C provides the main project documentation and complements:

* **Folder A – Source Code**, which contains the programming and Wokwi simulation files.
* **Folder B – Designs**, which contains the mechanical, electrical, system and engineering design documentation.

Together, these folders provide a complete record of the SOLAFORM Artificial Leaf project.
