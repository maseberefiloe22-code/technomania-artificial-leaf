# SOLAFORM – Designs

## Overview

This folder contains the design information for the SOLAFORM Artificial Leaf prototype.

The designs show how the physical structure, electronic components, and overall system are arranged to support the automatic CO₂ capture, regeneration, and conversion concept.

## Design Areas

The Folder B design documentation covers:

* Mechanical design
* Electrical and electronic design
* Overall system design
* Prototype layout and component arrangement
* Design drawings and diagrams

## Purpose

The purpose of the designs is to provide a clear representation of how the SOLAFORM prototype is planned and how its different components work together.

The design documentation supports the source code and Wokwi simulation contained in Folder A.

## Prototype Concept

The SOLAFORM system is designed around the following process:

**Solar Energy → CO₂ Capture → Regeneration → CO₂ Conversion**

The prototype uses electronic sensors, indicators and a microcontroller-based control system to represent and monitor these stages.

## Prototype Limitation

The Wokwi prototype is a control-system demonstration. It does not physically perform CO₂ absorption, thermal regeneration, or electrochemical conversion. These processes are represented conceptually through the prototype's control logic and system states.
